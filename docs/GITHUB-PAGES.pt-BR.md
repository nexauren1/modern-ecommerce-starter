# GitHub Pages — Demo Visual

O projeto completo usa Next.js server-side. Portanto, GitHub Pages não hospeda o Admin/API/Firebase/checkout da versão completa.

O Pages é usado para uma prévia visual estática.

## Ativação única

No GitHub:

1. Abra o repositório.
2. Entre em Settings.
3. Abra Pages.
4. Em Build and deployment, escolha GitHub Actions.
5. Volte para Actions e execute Deploy demo to GitHub Pages.

O workflow publica a pasta demo/.

URL esperada:

https://nexauren1.github.io/modern-ecommerce-starter/

Se o site ainda não abrir, confira a execução do workflow e Settings → Pages.

Nenhum secret da aplicação é incluído na demo.
